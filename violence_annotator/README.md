# 물리폭력 구간 어노테이터 — 사용설명서

영화 영상에서 **폭력 구간(시작~끝)**을 표시해서, 모델 학습용 정답 데이터(txt)를 만드는 도구.
mp4를 넣으면 → 1초당 2장 프레임으로 잘라 → 브라우저에서 넘겨보며 구간을 찍고 → txt로 저장한다.

> **무엇을 violence / neg_hard 로 볼지(판단 기준)는** 별도 문서 `../docs/annotation_guide.md`를 먼저 읽어주세요.
> 이 문서는 **도구 사용법**만 다룹니다.

---

## 1. 준비 (최초 1번만)

Python이 설치돼 있어야 합니다.

```powershell
# 1) 이 폴더로 이동
cd "C:\Users\windg\Desktop\SCHOOL\3-1\데이터엔지니어링\project2\violence_annotator"

# 2) 필요한 패키지 설치
pip install -r requirements.txt

# 3) 실행
python app.py
```

실행되면 브라우저에서 **http://127.0.0.1:5000** 접속. (창을 닫지 말고 켜둔 채로 작업)

## 3. 영상 불러오기 (셋 중 하나)

- **방법 A (추천):** 상단 **📂 mp4 선택 → 자동 추출** 클릭 → 파일 고르면 **바로 추출 시작**.
  진행률 바가 차오르고, 끝나면 자동으로 어노테이션 화면으로 넘어감.
- **방법 B:** 경로 입력칸에 로컬 mp4 경로 쓰고 **Enter**. (업로드 안 하므로 큰 파일에 유리)
- **방법 C:** 한 번 추출한 영화는 **"추출된 영화 불러오기" 드롭다운**에서 선택 → 즉시 작업.

> 추출된 프레임은 `images/{영화이름}/frame_000000.jpg …` 에 저장됩니다.

## 4. 프레임 이동

| 동작 | 키 / 조작 |
|---|---|
| 1프레임 이동 | `←` / `→` |
| 10프레임 이동 | `Shift` + `←` / `→` |
| 임의 위치로 점프 | 슬라이더 드래그 |

---

## 5. 구간 표시 (어노테이션)

같은 키를 **두 번** 눌러 시작/끝을 찍습니다.

| 라벨 | 방법 |
|---|---|
| **violence** | `1` (시작 프레임) → 이동 → `1` (끝 프레임) |
| **neg_hard** | `2` (시작) → 이동 → `2` (끝) |

- 진행 중(시작만 찍은 상태)에 취소: `Esc`.
- **표시한 구간은 타임라인 바에 색 블록**으로 보입니다 (violence=빨강, neg_hard=주황).
  **흰 세로선 = 현재 프레임** 위치.
- **잘못 찍은 구간은 그 색 블록을 클릭**하면 삭제됩니다.
- **표시 안 한 나머지 구간은 저장할 때 자동으로 neg_easy** 처리됩니다. (neg_easy는 직접 안 찍어도 됨)

## 6. 단축키 한눈에

| 키 | 기능 |
|---|---|
| `←` `→` | 1프레임 이동 |
| `Shift`+`←` `→` | 10프레임 이동 |
| `1` | violence 시작 / 끝 |
| `2` | neg_hard 시작 / 끝 |
| `Esc` | 진행 중 구간 취소 |
| `Ctrl`+`Z` | 실행취소 (직전 구간 추가/삭제 되돌리기) |
| `Ctrl`+`S` | 저장 |
| (타임라인 색블록 클릭) | 그 구간 삭제 |

---

## 7. 저장 & 결과물

- **`Ctrl`+`S`** 또는 우측 **저장 버튼** → `output/{영화이름}.txt` 생성.
- 저장하면 상태줄에 `✔ N scenes 저장됨 → 경로` 표시.

**출력 형식** (타임라인 전체를 빈틈없이 덮는 scene들):

```
[movie_id, scene_num, start_frame, end_frame, label]
```

예시:
```
[sample01, 0, 0,    135,  violence]
[sample01, 1, 136,  211,  neg_easy]
[sample01, 2, 212,  273,  neg_hard]
[sample01, 3, 274,  4469, neg_easy]
```

- `frame`은 **2fps(1초=2프레임) 기준 번호**.
- `label` ∈ `violence` / `neg_hard` / `neg_easy`.

---

## 8. 작업 팁

- **슬라이더로 쭉 훑어** 싸움 장면을 찾고 → 그 근처에서 **화살표로 정밀하게** 시작/끝을 잡으면 빠릅니다.
- 실수하면 망설이지 말고 **`Ctrl`+`Z`** 로 되돌리기.
- **neg_hard(춤·운동 등 헷갈리는 격한 동작)를 꼭 넉넉히** 찍어주세요. (모델이 폭력과 헷갈리지 않게 하는 핵심)
- 작업은 중간중간 **`Ctrl`+`S`** 로 저장. (같은 영화는 저장할 때마다 txt가 갱신됨)

---

## 9. 자주 묻는 문제

- **페이지가 안 열려요** → `python app.py` 창이 켜져 있는지 확인. 꺼졌으면 다시 실행.
- **추출이 오래 걸려요** → 영상이 길수록 오래 걸립니다 (37분 영상 ≈ 20초). 진행률 바로 상태 확인.
- **파일명에 한글/이모지가 있어요** → 동작은 하지만 경로 입력이 번거로우니 파일명을 간단한 영문으로 바꾸는 걸 권장.
- **같은 영화를 다시 추출하면?** → 기존 프레임을 덮어씁니다 (드롭다운으로 불러오면 재추출 불필요).
