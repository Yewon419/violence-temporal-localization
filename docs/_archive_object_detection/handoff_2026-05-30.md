## ✅ 빈 프레임 → negative 세트화 + false-negative 재검수 (2026-05-30)

박스를 지운 건 bbox만이고 프레임 이미지는 CVAT에 그대로 남음. "아무것도 없는 컷"은
버리지 말고 negative(배경) 샘플로 보존해야 FP완화 학습에 쓸모 (트로피·찻잔 등은 hard negative).
- **현황**: CVAT 8 task = 800 프레임. 두 차례 삭제 후 **박스 0개 = 734 프레임**(negative), 박스 있는 positive 66.
  그중 96은 P4 엄격검수에서 사람이 비운 확정 negative. (`scripts/cvat_negative_frames.py`, read-only)
- **false-negative 재검수**: 사람이 안 본 638 빈 프레임을 9-up 컨택트시트(`p4_neg_sheets/`, `scripts/p4_neg_sheets.py`)
  + 의심 셀 풀해상도 spot-check로 전수 스캔(`p4_neg_fn_ledger.md`). 목적: GD가 놓친 음주맥락 타깃 색출.
- **결과**: FN = **2건뿐**(둘 다 범죄와의전쟁: 00511 OB맥주크레이트+술잔, 00828 양주잔).
  나머지 배경 장식병·생수·청량음료·노래방 공연(술 미노출)·바둑판 등은 진짜 negative.
- **산출**(`scripts/p4_neg_finalize.py`): `p4_negative_frames.json` = **clean negative 732**(fn_checked) /
  `p4_false_negative_frames.json` = FN 2(누락 positive 후보, negative 아님).
- **저장 형태**: manifest만. 실제 export(배경 이미지 포함 여부·포맷)는 팀 회의/export 단계 결정.
- 스크립트 모두 mypy/ruff 통과.
