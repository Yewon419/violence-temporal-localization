# 물리폭력 구간 어노테이션 가이드 v2

> **목적:** 영화 클립에서 폭력 구간의 시작/끝을 CVAT로 표시해
> Step2 포즈모델의 학습·평가 정답(GT)을 만든다.
>
> **왜 정확해야 하나:** 이 라벨 품질이 모델 성능의 천장을 그대로 결정한다.

> **프레임 기준:** CVAT task는 **2fps**(1초에 2프레임)로 추출된 프레임으로 만든다.
> 따라서 가이드의 "프레임"은 전부 2fps 기준이다. (예: 5초 = 10프레임)

---

## 1. 라벨 (직접 찍는 건 2개)

| label | 정의 | 찍나? |
|---|---|---|
| **violence** | 폭력 장면 | ✅ 직접 표시 |
| **neg_hard** | 폭력 아닌데 움직임이 격해 헷갈리는 동작 (춤, 달리기, 격한 포옹/환호, 과장된 제스처, 장난 몸싸움, 운동) | ✅ 직접 표시 |
| **neg_easy** | 명백한 비폭력 (대화·보행·정지 등) | ❌ **표시 안 함** — 라벨 안 된 구간이 자동으로 neg_easy 처리됨 |

→ **violence + neg_hard만 찍으면 된다.** 나머지 빈 구간은 자동으로 비폭력.

---

## 2. 무엇이 violence인가

**포함:**

- 신체 접촉 가격: 주먹·발·머리·몸으로 치거나 제압. 목조르기, 메치기, 머리채, 짓누르기, 붙잡고 격투.
- 근접 흉기 격투: 칼·둔기를 휘두르며 몸싸움.
- **총격·총 겨눔 포함.**

**제외 (violence 아님):**

- 폭발·차량사고·재난(객체/이벤트).
- 언어 위협만(접촉·동작 없음).

---

## 3. 경계 규칙 (start_frame / end_frame)

- **시작:** **예비동작 포함.** 주먹 들어올리기·달려듦·겨눔 등 폭력 직전 동작부터.
- **끝:** 폭력이 끝나는 프레임.
- **병합은 널널하게:** 한 싸움 씬은 **통째로 한 구간.** 중간에 쉬는 타임이 **5초(2fps 10프레임) 이하면 끊지 말고 병합.**
- 5초 초과로 완전히 중단됐다 재개되면 별도 구간.

---

## 4. CVAT 작업 방법 (★ 비디오는 track으로 찍는다)

CVAT 비디오 export는 "구간 태그"를 지원하지 않으므로 **track(box)으로 구간을 표현**한다.

1. video 모드로 클립 열기.
2. 폭력 **시작 프레임**에서 **box 하나 그리기** (위치·크기는 대충 — 우리는 좌표 안 쓰고 track의 프레임 범위만 사용).
3. 생성된 **track의 label**을 `violence` 또는 `neg_hard`로 지정.
4. **끝 프레임**으로 이동 → 그 track을 **`outside`(사라짐)로 표시** (단축키). → 그 프레임이 구간 끝.
5. 한 클립에 여러 구간이면 구간마다 track 따로.

---

## 5. 출력 (export 형태)

- export 포맷: **`CVAT for video 1.1`** (XML).
- 구조: track마다 시작/끝 box.

```xml
<track id="0" label="violence">
  <box frame="120" keyframe="1" outside="0" xtl="..." ytl="..." xbr="..." ybr="..."/>
  <box frame="155" keyframe="1" outside="1" xtl="..." ytl="..." xbr="..." ybr="..."/>
</track>
```

- **우리가 파싱해서** → `(video_id, scene_id, start_frame, end_frame, label)`로 변환.
  - `start_frame` = track 첫 box의 frame
  - `end_frame`  = `outside="1"` box의 frame
  - `label`      = track의 label
  - box 좌표(xtl…)는 사용 안 함.
- **frame은 2fps 기준 index.** (downstream 포즈 추출 fps로 변환은 우리가 처리)

---

## 6. 수량 / 비율 목표

- 한 영화의 violence 구간은 **전부** 잡기(놓치지 말 것).
- **neg_hard를 넉넉히** 찍기(춤·운동·장난 등 헷갈리는 격한 동작). 이게 없으면 데모에서 격한 비폭력에 오발한다.
- 목표 비율 violence : neg_hard ≈ **1 : 3** 정도.
- neg_easy는 안 찍는다(자동).

---

## 7. 클립 끝낼 때 체크리스트

- [ ] violence 구간 다 잡았나 (놓친 싸움 없나)
- [ ] 시작=예비동작부터, 끝=폭력 종료 프레임 맞나
- [ ] 한 씬 통째로 병합했나 (5초 이하 소강은 안 끊었나)
- [ ] neg_hard 구간 같이 찍었나
- [ ] track의 시작 box + `outside` 끝 box 둘 다 있나

---

## 8. 알려진 한계

- 폭발·차사고: 스코프 밖(포즈 없음).
- 정적 "총 겨눔"(움직임 거의 없음)은 포즈 신호가 약함 → 모델이 잡기 어려운 케이스.

---

## 부록. 본 데이터 전 검증 (1편으로)

- CVAT export(`CVAT for video 1.1`)가 track 구조로 잘 나오고, 파싱 시 `(start_frame, end_frame, label)`이 깨끗이 복원되는지 1편으로 확인하고 본작업 시작.
